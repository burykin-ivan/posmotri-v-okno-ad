# Проект «Посмотри в окно»

Учебный проект, выполненный в рамках курса по веб-разработке.

## Описание
Проект представляет собой интерфейс для просмотра онлайн-трансляций из разных городов. В ходе работы была выполнена стилизация интерфейса с помощью CSS (Flexbox, кастомные формы, состояния элементов).

## Технологии
* HTML5
* CSS3 (Flexbox, анимации, кастомные чекбоксы)
* JavaScript (готовый скрипт из стартового репозитория)

## Как запустить
Просто откройте файл `index.html` в любом современном браузере или запустите его через Live Server в VS Code.
